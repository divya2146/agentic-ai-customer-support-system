# 🤖 Agentic AI Customer Support Automation System

An AI-powered multi-agent customer support automation platform built using FastAPI, Streamlit, SQLite, and AI orchestration agents.

---

# 🚀 Features

## ✅ Phase 1 — Ticket Management System
- Create support tickets
- Store customer issues
- FastAPI backend
- Streamlit dashboard

## ✅ Phase 2 — Database Integration
- SQLite integration
- Permanent ticket storage
- Database services layer

## ✅ Phase 3 — AI Ticket Intelligence
- AI ticket classification
- Priority detection
- Sentiment analysis
- Department assignment
- SLA prediction

## ✅ Phase 4 — Multi-Agent AI System
- Routing Agent
- Escalation Agent
- Resolution Agent
- Analytics Agent
- Orchestrator Agent

---

# 🧠 AI Agents Included

| Agent | Function |
|------|------|
| Classifier Agent | Categorizes support tickets |
| Priority Agent | Detects urgency |
| Sentiment Agent | Detects customer sentiment |
| Routing Agent | Routes tickets to departments |
| Escalation Agent | Detects escalation need |
| Resolution Agent | Generates response |
| SLA Agent | Predicts SLA |
| Analytics Agent | Ticket analytics |
| Orchestrator Agent | Coordinates all agents |
